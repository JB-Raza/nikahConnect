# NikahConnect

A production-ready Muslim matchmaking mobile application inspired by modern platforms like Muzz, built with a scalable architecture, strong security practices, and a premium user experience.

---

# Tech Stack

## Frontend

* React Native (Expo)

## Backend

* Node.js
* Express.js

## Database

* PostgreSQL

## Authentication

* JWT Authentication
* OTP Verification

## Storage

* AWS S3

## Notifications

* Firebase Cloud Messaging (FCM)

## Payments

* Stripe

## Real-Time Communication

* Socket.io
